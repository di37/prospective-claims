# notebooks

Read results and interpret them. Generate nothing.

Tables come from `reports/tables` and figures from `reports/figures`. A notebook may render and save a figure built by a shared builder in `src`, because the figure script renders the same builder to the same filename and the artifact stays reproducible. A notebook may not construct a figure inline and save it, and may not write tables at all.

The reason is provenance. A figure that exists only in a notebook's output cell cannot be regenerated by running anything, and quietly becomes wrong when the results behind it change.

`08_verify_invariants.py` checks both rules and exits non-zero on failure.

If a notebook needs a figure that does not exist, add the builder to `src` and register it in `06_make_report_figures.py`.
