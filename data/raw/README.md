# data/raw

Source data exactly as retrieved. Never edited, never regenerated by anything other than the pull scripts.

Two sources land here. Earnings-call transcripts come from the HuggingFace dataset named in the root README. Financial facts come from SEC Company Facts at `data.sec.gov`, pulled per CIK.

XBRL facts are stored as-first-reported. Company Facts serves the current value of a concept including restatements, and a restatement issued after a claim would leak information that was not available when the claim was made.
